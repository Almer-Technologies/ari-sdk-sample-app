The SDK ships as a binary, so no SDK source belongs here. Do not copy the
sources jar publishToMavenLocal also writes. LICENSE beside this file governs
the .aar. To refresh, from a leviathan checkout at the commit you want:

    ./gradlew :libs:ari-tool-sdk:publishToMavenLocal
    v=0.1.0; d=com/ari_os/ari-tool-sdk/$v
    cp ~/.m2/repository/$d/ari-tool-sdk-$v.{aar,pom,module} sdk-repo/$d/
    ./scripts/strip-sources-variant.sh sdk-repo/$d/ari-tool-sdk-$v.module

then update the commit above. A new version means a new directory here and the
version in app/build.gradle.kts.
